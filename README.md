This entry hands in one X post that quotes make.fun's make-your-own-bounty announcement: it shows how anyone can launch their own bounty on make.fun, with a photo of the bounty-creation page attached. main.ts copies POST.json, which names the post, to /output, where the gate reads it and scores its replies, reposts and quotes.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
